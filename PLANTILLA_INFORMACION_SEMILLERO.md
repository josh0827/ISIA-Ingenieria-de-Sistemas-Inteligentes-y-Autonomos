# Plantilla de información para el sitio web de ISIA

Esta lista reúne la información que el semillero debe validar y entregar para sustituir o complementar el contenido ilustrativo. No es necesario completar todos los apartados en una sola entrega. En cada caso debe indicarse quién confirmó la información y la fecha de revisión.

## 1. Identidad institucional

- [ ] Nombre oficial del semillero.
- [ ] Sigla autorizada.
- [ ] Descripción breve para la portada, de 40 a 70 palabras.
- [ ] Presentación ampliada, de 150 a 300 palabras.
- [ ] Objetivos aprobados.
- [ ] Facultad, departamento, campus y espacio físico confirmados.
- [ ] Nombre y cargo de la persona responsable del contenido.
- [x] Correo institucional de contacto: `isia_man@unal.edu.co`.
- [ ] Redes sociales oficiales, si existen.
- [ ] Escudo o recurso institucional autorizado y sus condiciones de uso.
- [ ] Fecha de última validación.

## 2. Líneas de investigación

Completar una ficha por cada línea aprobada:

- [ ] Nombre oficial.
- [ ] Descripción breve, de 40 a 80 palabras.
- [ ] Objetivo o pregunta principal.
- [ ] Temas relacionados.
- [ ] Persona responsable, si aplica.
- [ ] Proyectos vinculados.
- [ ] Confirmación de que puede publicarse como línea oficial.

## 3. Grupos de trabajo

Completar una ficha por grupo:

- [ ] Nombre.
- [ ] Descripción.
- [ ] Integrantes autorizados para aparecer.
- [ ] Imagen de portada con autorización y texto alternativo, si existe.
- [ ] Repositorios públicos, si existen. Este dato es opcional.
- [ ] Documentos públicos, si existen. Este dato es opcional.
- [ ] Fotografías autorizadas, pies de foto y créditos, si existen.

## 4. Proyectos

Completar una ficha por proyecto:

- [ ] Título.
- [ ] Estado: En formulación, Fase inicial o Prototipado.
- [ ] Línea de investigación relacionada.
- [ ] Resumen, de 50 a 100 palabras.
- [ ] Descripción completa: problema, propósito, método y alcance.
- [ ] Integrantes que autorizaron su publicación.
- [ ] Imagen principal autorizada y texto alternativo, si existe.
- [ ] Recursos o resultados públicos, si existen.
- [ ] Persona que validó la ficha y fecha de revisión.

## 5. Novedades

Completar una ficha por nota:

- [ ] Título.
- [ ] Fecha real de publicación o del hecho informado.
- [ ] Tipo: divulgación, evento, logro, publicación o convocatoria.
- [ ] Resumen.
- [ ] Texto completo.
- [ ] Autor responsable.
- [ ] Imagen autorizada, texto alternativo y crédito, si existe.
- [ ] Confirmación de vigencia cuando se trate de una convocatoria.

## 6. Reuniones

Completar una ficha por reunión que pueda hacerse pública:

- [ ] Título.
- [ ] Fecha y hora de Colombia.
- [ ] Modalidad: presencial, virtual o híbrida.
- [ ] Lugar o enlace autorizado.
- [ ] Resumen y agenda.
- [ ] Ponente o responsable, si aplica.
- [ ] Indicación de si es próxima o ya finalizó.
- [ ] Confirmación de que los datos pueden publicarse.

## 7. Integrantes

Completar una ficha por persona. Publicar únicamente datos autorizados:

- [ ] Nombre.
- [ ] Rol dentro del semillero.
- [ ] Área de interés.
- [ ] Presentación breve.
- [ ] Fotografía autorizada y texto alternativo, si existe.
- [ ] Enlaces profesionales que la persona desea publicar.
- [ ] Correo público, solo si existe autorización expresa.
- [ ] Confirmación de consentimiento para publicar el perfil.

## 8. Publicaciones y recursos

Completar una ficha por recurso real:

- [ ] Título.
- [ ] Año.
- [ ] Autores en el orden correcto.
- [ ] Tipo de recurso.
- [ ] Descripción breve.
- [ ] Enlace a la fuente oficial.
- [ ] DOI únicamente cuando exista y haya sido verificado.
- [ ] Confirmación bibliográfica y autorización de publicación.

## 9. Galería

Completar una ficha por fotografía real:

- [ ] Archivo original con resolución adecuada.
- [ ] Título.
- [ ] Texto alternativo descriptivo.
- [ ] Pie de foto con contexto.
- [ ] Año o fecha.
- [ ] Autor o crédito.
- [ ] Autorización de uso y de las personas identificables.

## 10. Prácticas e iniciativas

Completar una ficha por oportunidad vigente:

- [ ] Título.
- [ ] Organización responsable.
- [ ] Ubicación y modalidad.
- [ ] Descripción.
- [ ] Temas relacionados.
- [ ] Correo de contacto confirmado.
- [ ] URL oficial de postulación, si existe.
- [ ] Fecha límite o criterio de vigencia.
- [ ] Autorización de la organización para publicar la oferta.

## 11. Participación y contacto

- [ ] Procedimiento de vinculación al semillero.
- [ ] Fechas o periodos de recepción, si existen.
- [x] Canal institucional de contacto: `isia_man@unal.edu.co`.
- [ ] Persona o rol responsable de responder.
- [ ] Temas de interés que se desean destacar.
- [ ] Texto de privacidad si se incorpora un formulario en el futuro.
- [ ] Responsable y plazo de conservación de las manifestaciones de interés recibidas por el formulario.

## 12. Dominio y publicación institucional

- [ ] Unidad académica responsable del sitio.
- [ ] Docente responsable del trámite.
- [ ] Responsable técnico durante la vigencia del sitio.
- [ ] Dirección `unal.edu.co` asignada por la Universidad.
- [ ] Autorización o instrucción sobre alojamiento en Vercel y uso de Supabase.
- [ ] Asesoría y aval de UNIMEDIOS.
- [ ] Plantilla institucional recibida y aplicada.
- [ ] Tratamiento de datos personales aprobado.

## 13. Entrega de archivos

- [ ] Usar nombres descriptivos para las imágenes y documentos.
- [ ] Indicar el apartado del sitio al que pertenece cada archivo.
- [ ] Adjuntar créditos, licencias y autorizaciones.
- [ ] Evitar enviar contraseñas, claves de API o datos personales que no se publicarán.
- [ ] Registrar nombre de quien entrega, nombre de quien aprueba y fecha de aprobación.
