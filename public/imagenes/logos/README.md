# Logos de ISIA

- `isia-simbolo.jpg`: versión horizontal sin texto complementario. Se usa en el encabezado.
- `isia-con-texto.jpg`: versión completa con nombre y referencia a UNAL Manizales. Se usa en el pie de página.

Las rutas, dimensiones originales y proporciones visibles están centralizadas en `lib/marca.ts`. Para sustituir las imágenes en el futuro se pueden reemplazar estos archivos conservando sus nombres y proporciones aproximadas. Si las dimensiones o los márgenes cambian, solo debe ajustarse `lib/marca.ts`.

Los componentes recortan visualmente el margen blanco exterior y no modifican los archivos originales.
